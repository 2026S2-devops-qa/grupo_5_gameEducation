# Política de Trilhas de Aprendizagem

Documento institucional da Universidade Corporativa GameEducation. Define a ordem recomendada dos cursos do catálogo em cada área de atuação. Vigência: 2026.

## Regras gerais

- Cada trilha começa pelo curso de nível INICIANTE da área e avança para INTERMEDIARIO, AVANCADO e ESPECIALISTA.
- O colaborador pode pular um curso da trilha se já tiver o nível correspondente na avaliação de competências.
- Cursos de outra área podem ser feitos como complemento, desde que o gestor aprove.

## Trilha de DevOps

Indicada para quem quer automatizar entregas, operar infraestrutura e trabalhar com containers.

1. **Introdução a DevOps** (INICIANTE, 12 h): cultura DevOps, integração contínua, entrega contínua e versionamento com Git.
2. **Docker na Prática** (INTERMEDIARIO, 20 h): imagens, containers, Dockerfile multi-stage, volumes, redes e docker compose.
3. **Kubernetes para Produção** (AVANCADO, 40 h): pods, deployments, services, escalabilidade, observabilidade e operação em produção. Pré-requisito: Docker na Prática.

## Trilha de QA (Qualidade)

Indicada para quem quer garantir a qualidade do software e automatizar testes.

1. **Fundamentos de Agile Testing** (INICIANTE, 16 h): papel do QA em times ágeis, quadrantes de teste, BDD e critérios de aceite.
2. **Qualidade de Software** (INTERMEDIARIO, 24 h): pirâmide de testes, TDD, testes de integração, métricas de qualidade e cobertura.

## Trilha de Desenvolvimento

Indicada para quem desenvolve aplicações de negócio e quer evoluir para arquitetura.

1. **Java com Spring Boot** (INTERMEDIARIO, 40 h): APIs REST, injeção de dependência, Spring Data JPA, validação e testes.
2. **Arquitetura de Software e Microsserviços** (ESPECIALISTA, 36 h): monólito modular, microsserviços, arquitetura hexagonal, mensageria, API Gateway e decisões arquiteturais (ADR). Pré-requisito: Java com Spring Boot.

## Trilha de Dados

Indicada para quem trabalha com análise de dados e modelos de Machine Learning.

1. **SQL e Modelagem de Dados** (INICIANTE, 20 h): modelagem relacional, normalização, consultas SQL e índices.
2. **Machine Learning Aplicado** (AVANCADO, 36 h): preparação de dados, classificação, avaliação de modelos e colocação de modelos em produção. Pré-requisito: SQL e Modelagem de Dados.

## Trilha de Gestão

Indicada para líderes técnicos e para quem se prepara para assumir uma equipe.

1. **Liderança de Equipes Técnicas** (INTERMEDIARIO, 16 h): feedback, delegação, rituais ágeis, gestão de conflitos e desenvolvimento do time.

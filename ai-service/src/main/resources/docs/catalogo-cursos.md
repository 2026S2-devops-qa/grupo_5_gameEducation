# Catálogo de Cursos

Documento institucional da Universidade Corporativa GameEducation. Lista os cursos disponíveis no catálogo da plataforma, com área, nível e carga horária. Os títulos são exatamente os cadastrados na plataforma.

## Docker na Prática

Área DEVOPS, nível INTERMEDIARIO, 20 horas. Ensina a empacotar aplicações em containers: Dockerfile, imagens multi-stage, volumes, redes e docker compose para subir ambientes completos com um comando. Indicado para desenvolvedores e profissionais de DevOps que querem padronizar ambientes.

## Introdução a DevOps

Área DEVOPS, nível INICIANTE, 12 horas. Apresenta a cultura DevOps, integração contínua, entrega contínua, versionamento com Git e o ciclo de vida de uma entrega. Ponto de partida para quem quer crescer em DevOps.

## Kubernetes para Produção

Área DEVOPS, nível AVANCADO, 40 horas. Orquestração de containers com Kubernetes: pods, deployments, services, configmaps, escalabilidade horizontal, observabilidade e boas práticas para produção.

## Fundamentos de Agile Testing

Área QA, nível INICIANTE, 16 horas. O papel da qualidade em times ágeis, quadrantes de teste, BDD com Gherkin e escrita de critérios de aceite.

## Qualidade de Software

Área QA, nível INTERMEDIARIO, 24 horas. Pirâmide de testes, TDD, testes de unidade e de integração, cobertura de código, métricas de qualidade e testes de carga.

## Java com Spring Boot

Área DESENVOLVIMENTO, nível INTERMEDIARIO, 40 horas. Desenvolvimento de APIs REST com Spring Boot: controllers, injeção de dependência, Spring Data JPA, validação, tratamento de erros e testes.

## Arquitetura de Software e Microsserviços

Área DESENVOLVIMENTO, nível ESPECIALISTA, 36 horas. Monólito modular, microsserviços, arquitetura hexagonal, comunicação síncrona e assíncrona (REST e mensageria), API Gateway, modelo C4 e registro de decisões (ADR).

## SQL e Modelagem de Dados

Área DADOS, nível INICIANTE, 20 horas. Modelagem relacional, normalização, consultas SQL, junções, agregações e índices.

## Machine Learning Aplicado

Área DADOS, nível AVANCADO, 36 horas. Preparação de dados, modelos de classificação, avaliação de modelos, retreino e publicação de modelos como serviço.

## Liderança de Equipes Técnicas

Área GESTAO, nível INTERMEDIARIO, 16 horas. Feedback, delegação, rituais ágeis, gestão de conflitos e desenvolvimento das pessoas do time técnico.
